## Extensão: Novas Tecnologias com Python
Este repositório reúne os projetos desenvolvidos durante a aula de sábado da disciplina de <b>"Extensão: Novas Tecnologias"</b>, utilizando Python como linguagem principal.
Cada aula possui sua própria pasta, organizada por ordem, contendo os arquivos e códigos trabalhados em sala.

# Estrutura
- As pastas estão separadas por aula (ex.: aula1, aula2, etc.).

- Dentro de cada pasta estão os scripts, notebooks e exercícios correspondentes.

- Cada projeto explora diferentes aplicações modernas do Python, como:

- Automação de tarefas

- Análise de dados

- Desenvolvimento web com frameworks

- Integração com APIs

- Inteligência Artificial e Machine Learning

# Observação
Este repositório é exclusivamente para fins acadêmicos, acompanhando o progresso das aulas de extensão em Novas Tecnologias com Python.
